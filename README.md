# 🛒 Shopping Bill Generator

A beginner-friendly Python project that generates a shopping bill based on item names, prices, and quantities.

## ✨ Features

- Add multiple shopping items.
- Enter the price and quantity of each item.
- Automatically calculate the amount for each item.
- Calculate the total shopping bill.
- Display a neatly formatted bill.
- Type `done` to finish adding items.

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal inside the project folder.
4. Run the following command:

```bash
python shopping_bill.py
```
